Use landscape, actual size / 100%, two-sided printing and usually short-edge flip. Do not select the printer’s own booklet or multi-page layout. Drivers differ; check both sides and fold order before a full run. Manual-duplex reordering is not generated.

BEFORE THE FIRST FOLD

A little setup saves a lot of paper.

Four panels per sheet

One folded sheet holds four logical pages. Source pages stay in reading order within each signature; added blank panels close the last group.

Artwork, without stretching

Crop rectangles define what is placed. Each is fitted within its half-sheet with its original proportions. Small text can become smaller; inspect the exported PDF.

Keep the original

The source file is never overwritten. The new PDF contains imposed page artwork. Interactive features, annotations, structure and source document metadata are not retained.

No uploads, analytics, accounts or browser storage. Complex PDFs can still be slow within the file-size limit. Physical print, paper creep, folds, color accuracy and binding results are not verified. Full limits and supported inputs.
